# LifeOS Vision and Capability Model

**English** | [简体中文](./vision.zh-CN.md)

## 1. Mission

LifeOS is not meant to live life for people or merely produce more answers. Its mission is to:

> **Help people understand themselves, understand their world, form better judgment, take meaningful action, and continuously grow from experience.**

LifeOS should improve two kinds of capability at the same time:

1. **System Capability** — LifeOS's own ability to understand, diagnose, reason, plan, support action, learn, and adapt.
2. **Human Capability** — the user's own ability to think, judge, learn, act, reflect, adapt, and operate independently.

If the system becomes stronger while the user becomes more dependent, LifeOS has not fulfilled its mission.

```text
Problem

```

## 3. System Capability

LifeOS should evolve toward a complete intelligence loop:

```text
Observe
→ Understand
→ Diagnose
→ Think / Reason
→ Decide
→ Plan
→ Act / Support Action
→ Observe Result
→ Review
→ Learn
→ Adapt
```

### Understand
Model the relevant Self, Context, Role, Goal, people, constraints, risks, resources, rules, and unknowns.

### Diagnose
Distinguish among information gaps, model gaps, value conflicts, decision conflicts, capability gaps, execution problems, communication problems, emotion/energy problems, and structural responsibility-authority gaps.

### Reason
Help users build clearer models, assumptions, trade-offs, and judgments instead of only outputting conclusions.

### Plan
Convert direction into a minimum useful path, priorities, checkpoints, and revisit conditions.

### Support Action
LifeOS should not stop at analysis; important runs should connect to a real next action whenever appropriate.

### Learn / Adapt
Use outcomes, feedback, and new evidence to update Foundation Models, decision records, method choices, user patterns, preferences, and eventually a Personal LifeOS.

## 4. Human Capability Model

LifeOS should gradually strengthen the user's own capabilities.

### Self Awareness
Understand values, preferences, capabilities, limitations, emotions, patterns, and resources without turning single events into permanent identity labels.

### Situational Awareness
Understand roles, incentives, rules, power, resources, constraints, risks, and time windows.

### Problem Framing
Distinguish symptoms from underlying problems and know when reframing is necessary.

### Critical Thinking
Separate:

```text
Fact
Interpretation
Assumption
Opinion
Value
Unknown
```

and actively seek evidence and counterevidence.

### Systems Thinking
Understand causal relationships, feedback loops, delays, constraints, second-order effects, and local optimization risks.

### Decision Making
Make reasonable choices under uncertainty and know what evidence would change the decision.

### Communication
Build shared understanding, express views, listen, give feedback, handle disagreement, negotiate boundaries, and coordinate action.

### Execution
Turn intention into action, priority, cadence, feedback, and results.

### Learning
Select different strategies for different learning goals and convert knowledge into understanding, practice, application, and transfer.

### Reflection
Extract reusable lessons from experience rather than merely recording outcomes.

### Metacognition
Observe one's own cognitive process:

```text
Event
→ Interpretation
→ Assumption
→ Belief
→ Decision
→ Behavior
```

and recognize recurring biases, default assumptions, and thinking patterns.

### Adaptability
Reorient when context, role, goals, or rules change instead of mechanically reusing old answers.

## 5. Cognitive Calibration

Better cognition is not the same as greater confidence. The aim is confidence that better matches reality.

LifeOS should help users ask:

- What do I know?
- What do I not know?
- What do I merely think I know?
- What is the evidence?
- What is the counterevidence?
- What is my current confidence?
- What new evidence would change my judgment?

## 6. Mental Model Capability

LifeOS may develop a validated Mental Model Library, but the goal is not collecting models. The goal is selecting and applying the right models in the right situations.

Each model should explain what it is, what problem it solves, when to use it, when not to use it, common misuse, related models, real cases, practice, and transfer.

The Kernel should route models when useful rather than requiring the user to know model names in advance.

## 7. Knowledge → Wisdom

LifeOS should not differentiate itself by providing more information alone.

```text
Information
→ Knowledge
→ Understanding
→ Experience
→ Judgment
→ Wisdom
```

AI is naturally strong at Information and Knowledge. LifeOS should focus on strengthening Understanding, Judgment, Transfer, and Wisdom.

## 8. Capability Transfer

The best result of solving one problem is not only that the problem improves, but that the user becomes more capable of handling similar problems independently.

Transfer can be observed when users can explain the reasoning in their own words, recognize similar structures in new contexts, execute more of the process without LifeOS, or form reusable principles and methods.

## 9. Dependency Boundary

LifeOS should not optimize for maximum usage frequency. It should optimize for capability growth.

```text
Level 1  LifeOS gives answers
Level 2  LifeOS helps solve problems
Level 3  LifeOS helps users learn how to solve this class of problem
Level 4  LifeOS improves mental models and judgment
Level 5  Users can independently run more and more LifeOS capabilities
```

> **LifeOS succeeds when users become stronger, not merely when they become better at using LifeOS.**

## 10. Personal LifeOS

The long-term goal is not for every user to run one fixed framework:

```text
Default LifeOS
→ User Evidence
→ Self / Roles / Goals
→ Decision History
→ Actions / Outcomes
→ Experiences / Lessons
→ Patterns / Preferences
→ Personalized Runtime
→ My LifeOS
```

A mature LifeOS should increasingly resemble the user rather than the framework author.

## 11. Three Value Layers

```text
                    LifeOS
                      │
        ┌─────────────┼─────────────┐
        ↓             ↓             ↓
   Personal OS   Intelligence   Human Growth
```

- **Personal OS** — manage Self, Context, Role, Goal, Action, Review, and personal evidence.
- **Intelligence** — understand, diagnose, reason, select methods, plan, and adapt.
- **Human Growth** — improve cognition, judgment, action, learning, metacognition, and autonomy.

## 12. Ultimate Goal

```text
LifeOS
→ Solve Problems
→ Build Capability
→ Improve Cognition
→ Develop Judgment
→ Increase Autonomy
→ Become Your Own LifeOS
```

> **The ultimate goal of LifeOS is to help you become your own LifeOS.**
