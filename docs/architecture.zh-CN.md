# LifeOS 总体架构

## 1. 目标

LifeOS 的定位是一套可复用的个人操作系统，而不是一套固定的人生说明书。

其基本运行循环是：

```text
认识自己
   ↓
理解情境
   ↓
思考
   ↓
决策
   ↓
沟通
   ↓
行动
   ↓
观察
   ↓
复盘
   ↓
学习
   ↓
进化
```

## 2. 四层架构

### Layer 1 — Self / 自我

Self 层维护一个动态的个人模型，包括：

- 价值观；
- 目标；
- 优势；
- 局限；
- 兴趣；
- 能力；
- 责任；
- 关系；
- 资源；
- 当前人生阶段。

Self Model 永远不是永久标签，它会随着经历持续更新。

### Layer 2 — Core OS / 核心操作系统

LifeOS 的可复用核心能力包括：

1. Thinking / 思考
2. Decision / 决策
3. Communication / 沟通
4. Execution / 做事与执行
5. Learning / 学习
6. Emotion & Energy / 情绪与能量
7. Review / 复盘

连同 Self，一共构成 LifeOS 的八大核心系统。

### Layer 3 — Context / 情境

底层操作系统保持相对稳定，但具体策略必须根据情境调整。

Context 通常包括：

- Role / 角色
- Goal / 目标
- People / 相关人员
- Rules / 规则
- Resources / 资源
- Constraints / 约束
- Risks / 风险
- Time Horizon / 时间尺度

### Layer 4 — Playbooks / 情景操作手册

Playbook 将 LifeOS 核心能力组合成针对某一类现实问题的可执行流程。

例如：

- 接手陌生项目；
- 进入新的职位或角色；
- 处理意见冲突；
- 做重大人生决策；
- 学习一个陌生领域；
- 挽救一个正在失控的项目。

## 3. 核心运行原则

```text
稳定内核 + 动态情境 + 实战 Playbook + 反馈 = 持续成长
```

Core 提供可复用能力；Context 随环境变化；Playbook 面向具体问题组合能力；反馈则进一步更新人的认知、方法和未来行为。

## 4. 个性化方向

开源项目提供的是默认 LifeOS。

长期使用后，它应该逐渐演化为：

```text
LifeOS Default
      ↓
Personalized LifeOS
      ↓
我的原则
我的模型
我的方法
我的 Playbook
我的经历
我的经验与教训
```

LifeOS 的目的不是让用户依赖系统，而是增强自我认识、判断力、自主性和行动能力。

## 5. AI 原生方向

AI 版本不应只是简单地“问题 → 回答”，而应该运行结构化流程：

```text
现实情境
   ↓
Context Analysis / 情境分析
   ↓
Role Analysis / 角色分析
   ↓
Problem Classification / 问题分类
   ↓
LifeOS Core / 核心系统选择
   ↓
Playbook Routing / Playbook 路由
   ↓
Guided Thinking / 引导思考
   ↓
Decision Support / 决策支持
   ↓
Action Plan / 行动计划
   ↓
Review & Learning / 复盘与学习
```

AI 的定位是增强人的判断，而不是替代人的判断。
