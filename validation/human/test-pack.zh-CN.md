# LifeOS Real User Test Pack

> 本文件给测试协调者和参与者使用。测试真实问题，不提供标准答案。

## A. Participant Brief

LifeOS 是一套帮助人理解情境、形成判断、采取行动和复盘学习的个人操作框架。

本测试不是考你，也不是要求你认可 LifeOS。我们需要知道它在哪些情况下有帮助、没有帮助，甚至让问题变复杂。

请带来一个你**现在真实面对**、希望近期推进的问题。

你可以随时：

- 不回答某个问题；
- 停止测试；
- 不执行 LifeOS 给出的建议；
- 修改最终决定；
- 指出任何让你觉得多余、武断或不舒服的地方。

LifeOS 的输出是辅助判断，不替代你的决定。

## G. Test Coverage Suggestions

第一轮尽量覆盖，而不是强行凑齐：

- Self / Direction
- Career Decision
- New Role / Management
- Project / Execution
- Responsibility–Authority Gap
- Important Communication
- Learning
- Procrastination / Priorities
- Failure / Review
- Context Adaptation

真实问题优先于覆盖率。不要为了测试某个 LifeOS 模块诱导用户制造问题。
