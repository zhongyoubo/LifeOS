# LifeOS Blind A/B Evaluator Sheet

Evaluator 不应知道 A/B 来源。

## 评分维度

每个回答分别对以下指标打 1–5 分：

- Clarity — 是否让真正的问题更清楚？
- Context Fit — 是否真正使用用户情境，而不是泛化建议？
- Insight — 是否暴露重要但容易忽略的因素？
- Decision Support — 是否提升判断质量而不是替用户决定？
- Actionability — 是否形成可执行的下一步？
- Autonomy — 是否尊重用户价值、边界与最终决定权？
- Process Cost — 为获得这些价值，用户需要承担多少额外阅读、回答问题和认知负担？

其中前六项越高越好；Process Cost 越低越好：1 = 很轻，5 = 很重。

### Short Reason

只写最主要的 1–3 个原因，不猜测回答来源。

## Evaluation Discipline

- 不因回答更长而加分。
- 不因使用表格、术语或框架名而加分。
- 如果一个简单回答已经解决问题，额外结构应计入 Process Cost。
- 如果回答给出漂亮但未经用户确认的价值判断，应降低 Autonomy。
- 如果回答把假设写成事实，应降低 Clarity / Context Fit。
- 如果 Next Action 过大、过多或无法开始，应降低 Actionability。
