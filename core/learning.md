# Learning System

**English** | [简体中文](./learning.zh-CN.md)

## Purpose
Turn unknowns into capabilities that can be understood, applied, transferred, and continuously improved.

## Process
```text
Question → Map → Learn → Explain → Practice → Feedback → Correct → Apply → Transfer
```

## Principles
Start from questions and goals rather than resource collection. Build a knowledge map before deep detail. Output and practice are part of learning. Seek high-quality feedback. Distinguish exposure, understanding, performance, and transfer. Use retrieval and spacing for durable memory.

## Outputs
Knowledge Model, Skill, Practice Evidence, Feedback, Knowledge Gaps, Transfer Cases.

## Methods
Feynman Technique, Active Recall, Spaced Repetition, Deliberate Practice, Project-based Learning, Learning by Teaching.

## Failure Modes
Collecting instead of learning, excessive input, no practice, no feedback, memorizing conclusions without models, and inability to transfer knowledge.

## AI Guidance
AI can act as tutor, explainer, exercise generator, and feedback partner, but should avoid performing the essential cognitive work for the user. Questions should encourage active retrieval and explanation.
