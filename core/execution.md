# Execution System

**English** | [简体中文](./execution.zh-CN.md)

## Purpose
Turn decisions into sustained real-world action and observable outcomes.

## Process
```text
Outcome → Milestone → Next Action → Owner → Time → Execute → Checkpoint → Adjust → Complete
```

## Principles
Separate outcomes from activity. Reduce plans to explicit next actions. Important work needs ownership and checkpoints. Prefer short feedback cycles. Treat plans as current hypotheses rather than immutable commitments. Remove blockers before adding more tasks.

## Outputs
Action Plan, Milestones, Next Actions, Progress, Blockers, Adjustments, Outcome.

## Methods
GTD, Kanban, Time Blocking, Milestone Planning, OODA, Implementation Intentions.

## Failure Modes
Planning instead of acting, excessive task decomposition, too many priorities, long periods without feedback, confusing busyness with outcomes, and no stopping condition.

## AI Guidance
AI should translate abstract goals into next actions, identify dependencies and blockers, and support checkpoints. It should not create false productivity by generating excessive task lists.
