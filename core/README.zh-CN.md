# LifeOS Core OS / 核心运行系统

[English](./README.md) | **简体中文**

Core OS 是 LifeOS 在不同角色、工作和环境下可重复使用的基础能力层。

```text
                 Self / 自我
                     │
                   Context
                     │
                   Goal
                     ↓
┌────────────────────────────────────────────┐
│                 CORE OS                    │
│                                            │
│ Thinking → Decision → Communication        │
│    ↓          ↓            ↓               │
│  思考        决策          沟通              │
│                                            │
│ Execution → Learning                       │
│    ↓          ↓                            │
│  执行        学习                           │
│                                            │
│ Emotion & Energy → Review                  │
│     情绪与能量       复盘                    │
└────────────────────────────────────────────┘
                     ↓
                  Evolve
```

## 七大系统

| System | 目的 | 核心输出 |
|---|---|---|
| Thinking 思考 | 从信息形成理解 | 问题模型、假设、洞察 |
| Decision 决策 | 从理解形成选择 | 决策、取舍、承诺 |
| Communication 沟通 | 建立共同理解与协同 | 对齐、反馈、共识 |
| Execution 执行 | 把选择转化为结果 | 行动、里程碑、结果 |
| Learning 学习 | 把未知转化为能力 | 模型、技能、迁移能力 |
| Emotion & Energy 情绪与能量 | 管理真实运行状态 | 状态调节、恢复、注意力 |
| Review 复盘 | 把经历转化为经验 | Lessons、模型更新、行为改变 |

## 系统之间不是孤立的

LifeOS 不鼓励把七个系统理解为七套互不相关的方法论。真实问题通常跨越多个系统。例如：

```text
项目失败
  ↓
Thinking: 到底发生了什么？
Decision: 是否继续、调整还是停止？
Communication: 如何与相关人员对齐？
Execution: 下一步如何恢复？
Emotion & Energy: 如何处理压力和状态？
Review: 应该吸取什么经验？
Learning: 哪些能力需要升级？
```

后续每个 Core System 都采用统一规范：Purpose → Inputs → Process → Outputs → Principles → Methods → Failure Modes → Templates → AI Guidance。
