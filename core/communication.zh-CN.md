# Communication System / 沟通系统

[English](./communication.md) | **简体中文**

## Purpose
在不同认知、角色和利益之间建立足够的共同理解，使关系和行动能够继续推进。

## Process
```text
Intent → Audience → Context → Message → Channel → Listen → Feedback → Alignment → Follow-up
```

## Outputs
Shared Understanding、Feedback、Agreement/Disagreement、Commitment、Open Questions、Next Communication。

## Principles
- 先明确沟通目的。
- 区分事实、感受、解释和请求。
- 理解不等于同意。
- 重要信息确认对方实际理解，而不是只确认自己已经说过。
- 冲突优先处理问题、利益和边界，而不是攻击人格。
- 根据对象和情境调整表达，不改变事实诚信。

## Methods
Active Listening、Nonviolent Communication、SBI Feedback、Pyramid Principle、Difficult Conversation、Negotiation。

## Failure Modes
只表达不倾听、默认对方拥有相同背景、模糊请求、情绪升级、回避关键冲突、把沟通当说服、没有闭环。

## AI Guidance
AI 可辅助组织表达、模拟不同受众理解和发现歧义；不应操纵、冒充用户真实感受或通过技巧绕过他人自主选择。
