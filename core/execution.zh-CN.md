# Execution System / 执行系统

[English](./execution.md) | **简体中文**

## Purpose
把决定转化为现实世界中的持续行动和可观察结果。

## Process
```text
Outcome → Milestone → Next Action → Owner → Time → Execute → Checkpoint → Adjust → Complete
```

## Principles
- Outcome 与 Activity 分开。
- 把计划推进到明确的 Next Action。
- 重要任务必须有 Owner 和 Checkpoint。
- 小步反馈优于长期闭门执行。
- 计划是当前假设，不是承诺永不变化。
- 优先消除阻塞，而不是增加待办。

## Outputs
Action Plan、Milestones、Next Actions、Progress、Blockers、Adjustments、Outcome。

## Methods
GTD、Kanban、Time Blocking、Milestone Planning、OODA、Implementation Intentions。

## Failure Modes
计划替代行动、任务过度拆分、优先级过多、长期没有反馈、忙碌感替代结果、没有停止条件。

## AI Guidance
AI 应帮助把抽象目标转换成下一步行动、识别依赖和阻塞，并提醒检查点；不应通过生成大量任务制造虚假生产力。
