# Thinking System / 思考系统

[English](./thinking.md) | **简体中文**

## Purpose
把杂乱信息转化为对问题更可靠的理解，为决策提供基础。

## Scope
负责观察、澄清、拆解、分析、综合与形成假设；不负责最终选择和执行。

## Inputs
问题、事实、观察、数据、观点、约束、未知信息、自身经验。

## Process
```text
Observe → Clarify → Separate → Decompose → Analyze → Synthesize → Hypothesize → Test
观察      澄清       区分       拆解        分析       综合         假设          验证
```

关键动作：
1. 定义正在回答的问题。
2. 区分 Fact / Interpretation / Assumption / Opinion / Value / Unknown。
3. 将复杂问题拆成可分析部分。
4. 寻找因果、关系、约束和系统结构。
5. 形成多个解释，而不是过早锁定答案。
6. 找证据验证或推翻关键假设。

## Outputs
Problem Statement、Facts、Assumptions、Unknowns、Mental Model、Insights、Hypotheses、Questions。

## Principles
- 先定义问题，再解决问题。
- 不把观点当事实。
- 主动寻找反证。
- 复杂问题优先建立模型而不是堆信息。
- 允许“不知道”。
- 根据决策重要性控制分析深度。

## Methods
方法作为插件：First Principles、5 Whys、Systems Thinking、MECE、Second-order Thinking、Inversion、Scenario Analysis。

## Failure Modes
问题定义错误、确认偏误、信息过载、过度分析、单一视角、把相关性当因果、用复杂模型掩盖不确定性。

## Metrics
是否更清楚地定义了问题？关键假设是否显式？未知信息是否减少？理解是否足以支持下一步决策？

## AI Guidance
AI 应帮助澄清、提出替代解释和反证问题；必须标识推断和不确定性，不应用流畅表达制造虚假确定性。
