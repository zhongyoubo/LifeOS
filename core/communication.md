# Communication System

**English** | [简体中文](./communication.zh-CN.md)

## Purpose
Create sufficient shared understanding across different perspectives, roles, and interests so relationships and action can move forward.

## Process
```text
Intent → Audience → Context → Message → Channel → Listen → Feedback → Alignment → Follow-up
```

## Principles
Clarify intent first. Separate facts, feelings, interpretations, and requests. Understanding does not mean agreement. Verify actual understanding for important messages. Address problems, interests, and boundaries rather than attacking identity. Adapt expression to audience and context without compromising factual integrity.

## Methods
Active Listening, Nonviolent Communication, SBI Feedback, Pyramid Principle, Difficult Conversation, Negotiation.

## Failure Modes
Speaking without listening, assuming shared context, vague requests, emotional escalation, avoiding important conflict, treating communication only as persuasion, and failing to close the loop.

## AI Guidance
AI may structure messages, simulate audience interpretations, and expose ambiguity. It should not manipulate others, fabricate the user's feelings, or use techniques to bypass another person's autonomy.
