# LifeOS Core OS

**English** | [简体中文](./README.zh-CN.md)

Core OS is the reusable capability layer that operates across roles, jobs, and environments.

## Seven Systems

| System | Purpose | Core Output |
|---|---|---|
| Thinking | Turn information into understanding | problem models, hypotheses, insights |
| Decision | Turn understanding into choice | decisions, trade-offs, commitments |
| Communication | Create shared understanding and coordination | alignment, feedback, agreement |
| Execution | Turn choices into results | actions, milestones, outcomes |
| Learning | Turn unknowns into capability | models, skills, transfer |
| Emotion & Energy | Manage actual human operating state | regulation, recovery, attention |
| Review | Turn experience into learning | lessons, model updates, behavioral change |

The systems are not independent toolboxes. Real situations usually activate several systems together.

Each Core System will follow a common specification: Purpose → Inputs → Process → Outputs → Principles → Methods → Failure Modes → Templates → AI Guidance.
