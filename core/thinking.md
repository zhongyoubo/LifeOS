# Thinking System

**English** | [简体中文](./thinking.zh-CN.md)

## Purpose
Turn messy information into a more reliable understanding of a problem so decisions have a sound basis.

## Scope
Observation, clarification, separation, decomposition, analysis, synthesis, hypothesis formation and testing. Final choice and execution belong to other systems.

## Process
```text
Observe → Clarify → Separate → Decompose → Analyze → Synthesize → Hypothesize → Test
```

Separate Fact / Interpretation / Assumption / Opinion / Value / Unknown; create alternative explanations and seek evidence that can disconfirm important hypotheses.

## Outputs
Problem Statement, Facts, Assumptions, Unknowns, Mental Models, Insights, Hypotheses, Questions.

## Principles
Define before solving; do not confuse opinions with facts; seek disconfirming evidence; model complexity instead of merely collecting information; allow uncertainty; match analysis depth to decision importance.

## Methods
Optional plugins include First Principles, 5 Whys, Systems Thinking, MECE, Second-order Thinking, Inversion, and Scenario Analysis.

## Failure Modes
Wrong problem, confirmation bias, information overload, analysis paralysis, single-perspective reasoning, confusing correlation with causation, and hiding uncertainty behind complex models.

## AI Guidance
AI should clarify, generate alternative explanations, and challenge assumptions. It must identify inference and uncertainty rather than creating false certainty through fluent language.
