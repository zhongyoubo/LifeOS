# Learning System / 学习系统

[English](./learning.md) | **简体中文**

## Purpose
把未知逐渐转化为可以理解、应用、迁移和持续改进的能力。

## Process
```text
Question → Map → Learn → Explain → Practice → Feedback → Correct → Apply → Transfer
```

## Principles
- 从问题和目标出发，而不是从资料收藏出发。
- 建立知识地图后再深入细节。
- 输出和实践是学习的一部分。
- 优先获取高质量反馈。
- 区分“看过”“理解”“会做”和“能够迁移”。
- 使用间隔和检索强化长期记忆。

## Outputs
Knowledge Model、Skill、Practice Evidence、Feedback、Knowledge Gaps、Transfer Cases。

## Methods
Feynman Technique、Active Recall、Spaced Repetition、Deliberate Practice、Project-based Learning、Learning by Teaching。

## Failure Modes
收藏替代学习、输入过量、没有实践、没有反馈、只记结论不建模型、无法迁移。

## AI Guidance
AI 应作为导师、解释器、练习生成器和反馈伙伴，但要避免直接替用户完成关键认知过程；适当使用提问让用户主动检索和解释。
