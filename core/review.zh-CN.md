# Review System / 复盘系统

[English](./review.md) | **简体中文**

## Purpose
把经历转化为可复用的经验，并推动模型、原则、方法和行为发生真实更新。

## Process
```text
Expected → Actual → Gap → Cause → Lesson → Change → Verify
```

## Principles
- 复盘不是自我批评会。
- 结果与当时决策质量分开评价。
- 同时分析成功和失败。
- Lesson 必须能够影响未来行为，否则只是总结。
- 区分偶然结果和可重复能力。
- 对重要 Lesson 设置后续验证。

## Outputs
Facts、Gap、Causes、What Worked、What Failed、Lessons、Changes、Model Updates、Verification。

## Methods
After Action Review、Postmortem、Weekly Review、Decision Journal Review、Learning Review。

## Failure Modes
只找责任人、事后诸葛亮、泛泛而谈、每次得到相同教训、没有行为变化、只复盘失败不复盘成功。

## AI Guidance
AI 应帮助重建事实时间线、挑战事后偏见和发现重复模式；不能把相关性自动解释为原因，也不应替用户生成看似深刻但无法验证的 Lesson。
