# LifeOS Templates / 核心模板

[English](./README.md) | **简体中文**

模板的目标是让 LifeOS 在没有 AI 的情况下也可以直接使用。所有模板都应尽量短、可复制、可在真实问题中完成。

## 1. Problem Clarification / 问题澄清

```text
Situation：发生了什么？
Problem：真正的问题是什么？
Impact：为什么重要？
Facts：确定知道什么？
Assumptions：正在假设什么？
Unknowns：还不知道什么？
Desired Outcome：希望发生什么变化？
Next Question：最值得先回答的问题是什么？
```

## 2. Decision / 决策

```text
Decision：我要决定什么？
Why Now：为什么现在需要决定？
Goal：希望获得什么结果？
Options：有哪些真实选项？
Criteria：判断标准是什么？
Trade-offs：每个选择失去什么？
Risks：最重要风险是什么？
Reversibility：是否可逆？
Decision：最终选择什么？
Reason：为什么？
Revisit：什么条件下重新评估？
```

## 3. Role Profile / 角色画像

```text
Role：
Purpose：这个角色为什么存在？
Responsibilities：我负责什么？
Authority：我可以决定什么？
Expectations：别人合理期待我什么？
Boundaries：哪些不属于我的责任？
Relationships：关键协作关系有哪些？
Outcomes：如何判断这个角色履行得好？
Conflicts：与其他角色有什么冲突？
```

## 4. Goal Definition / 目标定义

```text
Direction：长期方向是什么？
Goal：具体想改变什么？
Why：为什么值得做？
Outcome：最终结果是什么？
Measure：如何判断进展？
Horizon：时间范围？
Cost：愿意付出什么？
Boundary：不愿牺牲什么？
Milestone：关键节点？
Next Action：下一步？
```

## 5. Action Plan / 行动计划

```text
Outcome：
Milestones：
Next Action：
Owner：
When：
Dependencies：
Blockers：
Checkpoint：
Stop / Adjust Condition：
```

## 6. Learning Plan / 学习计划

```text
Question：我要解决什么问题？
Capability：最终希望会做什么？
Knowledge Map：这个领域由哪些核心模块组成？
Known / Unknown：已知与未知？
Practice：如何练习？
Feedback：从哪里获得反馈？
Explain：如何证明自己真正理解？
Transfer：如何迁移到新场景？
Review：何时检查学习效果？
```

## 7. Communication / 沟通准备

```text
Intent：为什么沟通？
Audience：对方是谁？
Context：对方知道什么、不知道什么？
Facts：客观事实？
Interpretation：我的解释？
Need / Interest：真正关注什么？
Message：核心信息？
Request：希望对方做什么？
Listen：我需要理解对方什么？
Alignment：怎样算沟通完成？
```

## 8. Review / 复盘

```text
Expected：原本预期什么？
Actual：实际发生什么？
Gap：差异是什么？
What Worked：什么有效？
What Failed：什么无效？
Why：为什么？
Luck vs Skill：哪些是偶然，哪些可重复？
Lesson：未来可复用的经验？
Change：下次具体改变什么？
Verify：如何验证这个 Lesson？
```


对于复杂问题，优先使用 `lifeos-run.zh-CN.md` 运行完整 LifeOS Runtime。
