# LifeOS Golden Playbooks / 黄金场景方案

[English](./golden-playbooks.md) | **简体中文**

Golden Playbooks 用于验证 LifeOS Runtime 是否真的能够解决典型真实问题。它们不是固定答案，而是标准化的问题处理路径。

## 1. 面对复杂问题，不知道怎么办

**适用场景**：信息混乱、问题模糊、不知道从哪里开始。

```text
Clarify Problem
  ↓
Separate Facts / Assumptions / Unknowns
  ↓
Map Context
  ↓
Decompose
  ↓
Identify Highest-Leverage Question
  ↓
Choose Smallest Useful Next Action
  ↓
Observe Feedback
```

激活：Thinking → Execution → Review。

关键问题：真正的问题是什么？如果只能解决一个子问题，哪个最重要？现在最缺的是信息、选择还是行动？

## 2. 做一个重要决定

**适用场景**：换工作、搬家、投资时间、选择项目、重要关系选择等。

```text
Clarify Goal & Values
  ↓
Generate Real Options
  ↓
Define Criteria
  ↓
Analyze Trade-offs & Risks
  ↓
Check Reversibility
  ↓
Decide
  ↓
Define Revisit Condition
```

激活：Self + Goal + Thinking + Decision + Emotion & Energy。

关键问题：我真正优化的是什么？什么是不能牺牲的边界？哪些后果可逆？不选择也是一种选择吗？

## 3. 进入新的角色、岗位或环境

**适用场景**：晋升、转岗、加入新团队、成为管理者、父母或其他新角色。

```text
Define Role Purpose
  ↓
Clarify Responsibilities / Authority / Expectations
  ↓
Map Stakeholders
  ↓
Identify Existing Strengths & Gaps
  ↓
Create 30/60/90-day Outcomes
  ↓
Build Feedback Loop
```

激活：Role + Context + Learning + Communication + Execution + Review。

关键问题：这个角色为什么存在？别人真正期待什么结果？哪些旧习惯在新角色里可能失效？

## 4. 接手一个陌生或复杂项目

**适用场景**：项目救火、陌生领域、信息不完整、责任复杂。

```text
Understand Outcome
  ↓
Map System / Stakeholders / Constraints
  ↓
Reconstruct Current State
  ↓
Identify Risks & Unknowns
  ↓
Find Critical Path
  ↓
Align People
  ↓
Create First Checkpoint
```

激活：Thinking + Learning + Communication + Execution + Decision。

关键问题：项目真正的成功标准是什么？现在最危险的未知是什么？谁拥有关键信息和决策权？

## 5. 与他人发生重要分歧或冲突

**适用场景**：工作冲突、合作分歧、重要关系沟通。

```text
Regulate State
  ↓
Separate Fact / Interpretation / Emotion
  ↓
Clarify Own Need & Boundary
  ↓
Understand Other Side's Interest
  ↓
Communicate
  ↓
Find Agreement / Disagreement
  ↓
Define Next Step or Boundary
```

激活：Emotion & Energy + Thinking + Communication + Decision。

关键问题：我们是在事实、解释、目标、利益还是价值上不同？我真正希望对方理解什么？无法达成一致时边界是什么？

## 6. 学习一个完全陌生的领域

**适用场景**：新技术、新行业、新岗位能力、跨领域学习。

```text
Define Capability Goal
  ↓
Build Knowledge Map
  ↓
Identify Fundamentals
  ↓
Learn Minimum Theory
  ↓
Practice on Real Problem
  ↓
Get Feedback
  ↓
Explain / Teach
  ↓
Transfer
```

激活：Learning + Thinking + Execution + Review。

关键问题：我最终需要“知道”还是“会做”？这个领域最基础的模型是什么？什么项目可以最快暴露理解漏洞？

## 7. 重要事情失败后的复盘与恢复

**适用场景**：目标失败、项目失败、重大错误、挫折。

```text
Stabilize State
  ↓
Reconstruct Facts
  ↓
Expected vs Actual
  ↓
Separate Decision Quality / Execution / Luck
  ↓
Find Causes
  ↓
Extract Testable Lessons
  ↓
Define Changes
  ↓
Restart with Small Action
```

激活：Emotion & Energy + Review + Thinking + Learning + Execution。

关键问题：实际发生了什么？哪些在我控制内？哪些 Lesson 真正能改变未来行为？下一步恢复行动是什么？

## Playbook Rule

所有 Golden Playbook 都必须遵循：

```text
Playbook ≠ Answer
Playbook = Context-sensitive execution path through LifeOS
```

当实际情况与 Playbook 假设不匹配时，应回到 Operating Protocol，而不是强行套模板。
